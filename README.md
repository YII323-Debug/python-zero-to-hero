# Python 闯关岛 · 零基础学编程

一个面向**完全零基础**学习者的 Python 闯关教学网页小游戏。不懂变量、字符串、语法也没关系——从"让电脑输出一句话"开始，一关一关走到独立完成小型项目。

## 特色

- **20 关循序渐进**：print → 变量 → 数字计算 → input → if 判断 → 布尔与 == → for 循环 → 列表 → 函数 → 文件读写，再到 while、字符串进阶、字典、列表进阶、逻辑运算、异常、递归、类与对象，最后两个综合项目（记账本 / 单词打卡工具）。
- **真实可写代码**：内置一个纯 JavaScript 实现的 Python 子集解释器，学员写的 `print`、`input`、变量、计算、`if/else`、`for`、`while`、列表、字典、`def`、类、文件读写等都会真实运行。
- **大白话报错**：错误全部翻译成中文口语提示（如"引号没有成对"），不甩英文 Traceback。
- **严格解锁 + 自动批改**：必须"动手任务通过批改 + 小检测答对"才解锁下一关；写错先肯定思路再给线索，卡住只给提示不给完整答案。
- **防泄题设计**：示例只教方法，任务换成新场景；提示只有思路线索没有答案代码。
- **A/B 双题组**：点"重新开始"会切换到一套全新题目（任务、提示、检测全换，示例不变），防止背答案。
- **进度保存**：自动保存 + 手动"保存进度"按钮 + 导出/导入备份文件，换浏览器也能找回进度。

## 教学规则

1. 闯关制，完成当前关的练习 + 小检测才解锁下一关，不提前剧透。
2. 拒绝专业黑话，术语第一次出现必用生活化类比，先举例感受再命名概念。
3. 每关固定结构：引入 → 极简知识点 → 逐行注释示例 → 动手任务 → 自动批改 → 通关判定。
4. 讲底层原理（内存、解释器等）一律不讲。
5. 卡住只给线索，不贴完整答案；写错先肯定对的部分再指出问题。
